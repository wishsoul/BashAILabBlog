AI-generated native interfaces need more than visual instructions if they are to remain consistent across design and implementation.

This research direction organizes constraints through rules, design tokens, a runtime, validators, and code generation. MacNativeKit is the associated infrastructure profile for exploring that system on macOS with SwiftUI and AppKit.

No public performance result or comparative metric is claimed in this initial note.
